# Google Docs

Read, create, and edit documents with Google Docs.

Connects agents to [Google Docs](https://docs.google.com/document) through Google's remote [Model Context Protocol](https://modelcontextprotocol.io/) server at `https://docsmcp.googleapis.com/mcp/v1`. Requires an eligible Google Developer Preview account.

Auth is OAuth 2.0 against Google.

## Docs

- Google MCP setup: https://developers.google.com/workspace/docs/api/guides/configure-mcp-server
- Workspace MCP overview: https://developers.google.com/workspace/guides/configure-mcp-servers
