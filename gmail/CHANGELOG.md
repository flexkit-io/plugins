# Changelog

All notable changes to this plugin will be documented here.

## 1.1.0

- Now maintained as a first-party Flexkit plugin. No longer vendored from `cursor/plugins`, whose package now points at a Cursor-hosted MCP endpoint.
- The `gmail` MCP server still points at Google's endpoint, `https://gmailmcp.googleapis.com/mcp/v1`.

## 1.0.0 — initial release

- Logo: official Gmail 2026 product icon from Google productlogos, on a padded white tile.
- Added the `gmail` MCP server pointing at `https://gmailmcp.googleapis.com/mcp/v1`.
