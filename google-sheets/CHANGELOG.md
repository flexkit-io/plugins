# Changelog

All notable changes to this plugin will be documented here.

## 1.0.1

- No longer requests `drive.readonly`. The plugin works on the documents the user names or opens through Flexkit (`drive.file`), so connecting no longer asks to see every file in Google Drive.

## 1.0.0 — initial release

- Logo: official Google Sheets 2026 product icon on a white tile.
- Added the `google-sheets` MCP server pointing at `https://sheetsmcp.googleapis.com/mcp/v1`.
