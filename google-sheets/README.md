# Google Sheets

Read, create, and update spreadsheets with Google Sheets.

Connects agents to [Google Sheets](https://docs.google.com/spreadsheets) through Google's remote [Model Context Protocol](https://modelcontextprotocol.io/) server at `https://sheetsmcp.googleapis.com/mcp/v1`. Requires an eligible Google Developer Preview account.

Auth is OAuth 2.0 against Google.

## Docs

- Google MCP setup: https://developers.google.com/workspace/sheets/api/guides/configure-mcp-server
- Workspace MCP overview: https://developers.google.com/workspace/guides/configure-mcp-servers
